# 🎮 Tic Tac Toe

A simple **Tic Tac Toe** game built using **HTML, CSS, and JavaScript**. It allows two players to play against each other by taking turns as Player 1 (X) and Player 2 (O).

🌐 [**Live Demo**](YOUR_LIVE_LINK_HERE)

![Tic Tac Toe Screenshot](https://github.com/sunny1901kumar-sys/Tic-Tac-Toe/raw/main/Screenshot1.png)

## ✨ Features

* ❌ Player 1 plays with X
* ⭕ Player 2 plays with O
* 🔄 New Game button to restart the game
* 🏆 Detects the winner
* 🤝 Detects a draw
* 🟩 Highlights the winning cells
* ⛔ Stops the game after a winner or draw
* 🚫 Prevents selecting an already filled cell

## 🛠️ Technologies Used

* **HTML** – Structure
* **CSS** – Styling and layout
* **JavaScript** – Game logic, DOM manipulation, and event handling

## 🚀 How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
